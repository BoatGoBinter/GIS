**This app helps solve the problem of understanding how January snow cover on Ulleung Island has changed over time and how snowy conditions differ between selected years.**

I used the Sentinel-2 NDSI (Normalized Difference Snow Index) from Copernicus to identify snow from satellite coverage. **It uses the MODIS Terra Snow Cover Daily Global 500m ImageCollection, MODIS/061/MOD10A1, specifically the NDSI_Snow_Cover band, to measure January snow cover on Ulleung Island.** The Ulleung Island study area is defined manually using an ee.Geometry.Rectangle around the island rather than a separate FeatureCollection. To make this project slightly more simplified for both me and the user, I decided that I would only use January as the chosen month for the year. I chose January because it is generally the most consistent month for Ulleung-do to receive the most snow, with February being a close second.[^1] I think comparing years is better to understand how much snow Ulleung; thus, using only one month simplifies everything. My app has a title and written instructions that explain what the app does, displays, and calculates. The user can choose a single year to display a continuous NDSI snow-index map. The lower values will be green while the stronger snow values are white and blue.

I also included a comparison mode. This allows the user to compare two different years. In this mode, the app will use a slider where they set a threshold to what pixels are classified as snow or non-snow which is based on the NDSI value of each pixel. After clicking “Load Snow Map,” the map will show areas where snow appears only in the first selected year in green, areas where snow appears only in the second selected year in fuchsia, and areas where snow appears in both selected years in white. This adds more analytical ability as we can see comparison between years. I also added an opacity slider (defaulted to .65, which is my favorite) so the user can see the island’s underlying landscape and terrain beneath the NDSI snow-index layer.

Lastly, at the bottom my map has a chart that is created from the same NDSI data in the map. It summarizes the meaning of January NDSI value across the rectangle area I made for Ulleung for each year. Since I used a square study area instead of a precise polygon for Ulleung, some ocean pixels are included in the map and chart, so the values should be interpreted as a relative snow index rather than an exact snowfall or snow depth.

**How to:** If you want to do a single year, make sure “Compare two years” is unchecked, then select the year and layer opacity. Finally click “Load Snow Map”. If you want to do a comparison, click the “Compare two years” box so it is checked. Then, select the two years you want to compare and use the snow threshold bar to set the minimum NDSI value needed to count as snow. Finally, if you want to see a bigger view of the chart, click the top right box with an arrow in it to open it in a new tab.

**Methodology:**

The methodology is quite simple. The app filters the MODIS daily snow-cover ImageCollection to Ulleung Island and to January of each selected year, removes invalid snow-cover values, calculates the mean January snow-cover percentage, and then displays either a single-year snow map or a two-year comparison showing areas where snow appears in only one year or in both years.

The main issue I had was trying to make a polygon for Ulleungdo. In the end, I think the square is fine for a class project like this. Another addition I may add in the future is a snow threshold for the single year map. In theory, you can do this by picking the same year in the comparison mode but that isn’t really intuitive. Also, some years are missing a lot of data points (anything with no coloring) like 2017 which was a major problem for this year specifically.

I learned a few cool things while researching. When I looked at 2017, I saw almost no coverage but was sure this was missing data. However, I decided anyway to search “울릉도 2017 강설” (Ulleung Island 2017 Snowfall) and found that they had a major snowstorm in February instead of January.[^2] Because of this, I saw it necessary to put that in the bottom graph to compare. Overall, I had fun with this project and got to learn a lot about Ulleungdo!
